# Darrell Burns

Darrell Burns’s personal website at https://darrilla.github.io/, published by
GitHub Pages from `Darrilla/darrilla.github.io` on `main`.

The homepage and About page introduce Darrell and link to his personal GitHub
profile, the Darrilla Software website, and the software account’s repositories.

Darrilla Software lives at https://darrilla.com/ in the separate repository
`darrilla-software/darrilla-software.github.io`. The old game, support, and privacy
URLs on this personal site redirect to their matching pages there. They are
excluded from this site’s sitemap. Retained studio assets, verification files,
and `app-ads.txt` preserve existing URLs.

This repository must not contain a `CNAME` for `darrilla.com`; the custom domain
belongs to the software account’s site. The canonical personal-site URL in
`_config.yml` is `https://darrilla.github.io`.

## Local preview

```sh
bundle install
bundle exec jekyll serve
```

Open http://127.0.0.1:4000. For a static build, run
`bundle exec jekyll build`.
