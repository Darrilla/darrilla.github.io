# Chess Clock

Chess Clock is a local two-player chess timer for over-the-board play.

It is built for quick setup, clear readability, and a physical-feeling
board-side experience.

## What It Does

- start a game with one tap
- switch turns by tapping the opposite side
- choose a shared time control for both players
- use optional Fischer increment in the standard setup flow

## Pro Unlock

Chess Clock includes an optional one-time Pro unlock.

Pro currently adds advanced delay timing options. The free app remains usable
without a purchase.

No app account or backend is required.
